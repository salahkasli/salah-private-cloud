# Hardware Inventory

## Main server

| Part | Configuration |
|---|---|
| Model | Lenovo ThinkCentre M720s SFF |
| CPU | Intel Core i5, 9th generation |
| RAM | 16 GB |
| System storage | 256 GB SSD |
| Data storage | 2 TB HDD |
| Backup storage | 1 TB HDD |

## What each disk is used for

- **256 GB SSD:** runs the host and virtual machine storage.
- **2 TB HDD:** stores the Immich photo and video library.
- **1 TB HDD:** stores database backup files.

## Notes

The two HDDs are installed in the same computer. They are separate storage volumes, not an independent backup location.

This inventory describes the current setup. It can be updated if hardware changes.
